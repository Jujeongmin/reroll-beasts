## 받는 법

itch.io 는 name-your-own-price 라 결제 창이 뜬다.
**`Download Now` → `No thanks, just take me to the downloads`** 를 누르면 0원으로 받는다.

각 팩의 zip 을 풀어서 아래 경로에 그대로 넣는다. 폴더명을 정확히 지켜라 —
가공 도구가 이 이름으로 찾는다.

```
art-src/
├─ medieval-warrior-pack/
├─ medieval-warrior-pack-2/
└─ ...
```

zip 안의 폴더 구조는 팩마다 다르다. **풀어서 나온 내용물을 위 폴더 안에 넣으면 된다**
(한 겹 더 감싸도 상관없다 — 도구가 재귀로 찾는다).

## 진행 확인

받는 중에 언제든 돌려서 뭐가 남았는지 본다:

```bash
node tools/check-art.mjs
```

받은 팩 · 남은 팩 · 각 폴더의 PNG 개수를 뱉는다.

## 받은 뒤 내가 할 일

1. 각 팩의 실제 내부 구조를 확인한다 (스프라이트시트 파일명·프레임 수·여백이 팩마다 다르다)
2. 시트 → 스트립 변환 도구를 쓴다 (`tools/` 에 추가)
3. 불투명 bbox 를 뽑아 `trim.json` 생성 — 유닛마다 캔버스 여백이 달라 발밑 정렬이 어긋난다
4. `game/public/assets/units/<unit_id>/<anim>.png` 로 배치
5. `units.json` 의 `sprite` 필드와 대조하는 검사를 `tools/validate.mjs` 에 추가

**1번을 받기 전에 추측으로 진행하지 않는다.** 팩마다 프레임 크기와 정렬이 달라서
실물을 보고 도구를 짜야 한다.
