# 한국어·영어 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 게임 전체가 한국어와 영어로 뜬다. 설정에서 바꾸면 그 자리에서 갈린다.

**Architecture:** 문자열 표 하나(`game/src/i18n.js`)가 키 → 문장을 쥔다. 화면은
`t('key')` 로만 읽고, 데이터의 이름·설명은 `{ ko, en }` 객체를 `textOf()` 가
푼다. **서버가 보내는 사유는 코드로 바꾼다** — 한국어 문장을 그대로 보내면
영어 화면에 한국어가 뜬다.

**Tech Stack:** 바닐라 JS(ESM) · vitest · 데이터는 `game/public/data/*.json`

## Global Constraints

- 기존 규칙 그대로: `sim/` 은 순수, 판정은 서버, 주석은 **왜**를 적는다
- 언어는 **기기 저장**(`rr.lang`). 계정에 두면 값 하나에 서버 왕복이 필요하고,
  기기마다 다른 언어를 쓰는 사람이 있다
- 저장된 값이 없으면 `navigator.language` 를 본다 — 처음 온 사람에게 묻지 않는다
- **키가 없으면 키를 그대로 그린다.** 빈 화면보다 낫고, 빠뜨린 자리가 눈에 띈다
- 각 Task 끝에서 `npm run check` 초록. 서버를 건드린 Task 는 서버 테스트도

`game/src/i18n.js`. 표는 이 Task 에서 **뼈대만** 채운다(패스·설정 등 Task 3·4 가

```js
// 문자열 표.
//
// **키가 없으면 키를 그대로 그린다.** 빈 화면보다 낫고, 빠뜨린 자리가 화면에서
// 바로 눈에 띈다 — 조용히 빈칸으로 두면 배포 뒤에야 발견한다.
//
// 언어는 기기에 저장한다(rr.lang). 계정에 두면 값 하나 바꾸는 데 서버 왕복이
// 필요하고, 기기마다 다른 언어를 쓰는 사람이 있다.

const LANG_KEY = 'rr.lang'

export const STRINGS = {
  ko: {
    'menu.normal': '일반 매치',
    'menu.ranked': '랭크 매치',
    'menu.tutorial': '튜토리얼',
    'menu.skins': '꾸미기',
    'menu.shop': '상점',
    'menu.settings': '설정',
    'pass.level': '{n}단계',
  },
  en: {
    'menu.normal': 'Normal',
    'menu.ranked': 'Ranked',
    'menu.tutorial': 'Tutorial',
    'menu.skins': 'Cosmetics',
    'menu.shop': 'Shop',
    'menu.settings': 'Settings',
    'pass.level': 'Lv {n}',
  },
}

let current = null

/** 지금 언어. 저장된 값이 없으면 기기가 쓰는 언어를 따른다. */
export function lang() {
  if (current) return current
  try {
    const saved = localStorage.getItem(LANG_KEY)
    if (saved === 'ko' || saved === 'en') return (current = saved)
  } catch {
    // 저장소를 못 읽는 브라우저가 있다. 기기 언어만 본다.
  }
  const nav = String(globalThis.navigator?.language ?? 'ko').toLowerCase()
  return (current = nav.startsWith('ko') ? 'ko' : 'en')
}

/** 언어를 바꾼다. 화면은 부르는 쪽이 다시 그린다. */
export function setLang(v) {
  current = v === 'en' ? 'en' : 'ko'
  try {
    localStorage.setItem(LANG_KEY, current)
  } catch {
    // 못 적어도 이번 판에는 바뀐다.
  }
  return current
}

/** 키 → 문장. {n} 같은 자리는 vars 로 채운다. */
export function t(key, vars) {
  const table = STRINGS[lang()] ?? STRINGS.ko
  let s = table[key]
  if (s == null) return key
  if (vars) {
    for (const [k, v] of Object.entries(vars)) s = s.split(`{${k}}`).join(String(v))
  }
  return s
}

/**
 * 데이터에 든 이름·설명. `{ ko, en }` 이면 지금 언어를, 문자열이면 그대로.
 *
 * 문자열도 받는 이유: 데이터 파일을 한 번에 다 옮기지 않는다. 아직 한국어만
 * 있는 줄도 화면에는 떠야 하고, 그래야 옮기는 도중에도 게임이 돈다.
 */
export function textOf(field) {
  if (field == null) return ''
  if (typeof field === 'string') return field
  return field[lang()] ?? field.ko ?? field.en ?? ''
}

/** data-i18n 이 붙은 요소를 채운다. 정적 문구는 이 한 번으로 끝난다. */
export function applyStatic(root = document) {
  for (const el of root.querySelectorAll('[data-i18n]')) {
    el.textContent = t(el.dataset.i18n)
  }
  for (const el of root.querySelectorAll('[data-i18n-aria]')) {
    el.setAttribute('aria-label', t(el.dataset.i18nAria))
  }
}
```

    ['미션', data.missions?.missions ?? []],

  for (const [what, list] of named) {
    for (const x of list) {
      if (!both(x.name)) errors.push(`${what} ${x.id} 의 이름에 영어가 없다`)
      if (x.desc && !both(x.desc)) errors.push(`${what} ${x.id} 의 설명에 영어가 없다`)
      if (x.text && !both(x.text)) errors.push(`${what} ${x.id} 의 문구에 영어가 없다`)
