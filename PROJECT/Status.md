# Status — Reroll Beasts

## Implemented

- **결정론 전투 시뮬** — 로그 재생만으로 화면이 복원된다. 골든 로그 2종으로 고정
- **배치·상점** — 구매 · 3합성 · 판매 · 리롤 · 경험치, 3D 대기석 드래그
- **로비 8인** — 나 + 봇 7. 라운드마다 같은 `simulate` 로 서로 싸워 체력이 깎인다
- **23라운드 진행** — 스테이지별 PvE 편성, 패배 피해, 이자·연승 정산
- **3D 무대** — 직사각 단상 + 벌집 표시, 해자·물가, 성급 배지, 원거리 투사체
- 유닛 탭 → 스탯·스킬·사거리 / 시너지 hover → 단계 효과·구성 유닛
- **아이템 12종** — 정해진 7개 라운드에 랜덤 지급, 유닛당 3칸, 드래그 장착.
  반사·흡혈·오라·관통이 전투에 붙는다. 봇도 같은 규칙으로 받는다

- **실시간 정찰 송신** — 배치 중 판이 바뀔 때마다 서버로 보낸다. 250ms
  쓰로틀(정찰용), 전투 직전 확정 송신은 쓰로틀 없음(판정 근거라 유실 금지)
- **매칭 큐 2종** — 일반은 시간이 차면 사람 + 봇으로 시작한다. 랭크는 사람 8명이
  찰 때까지 기다리고, **LP 는 랭크 방에서만** 움직인다 — 봇이 섞인 판이 점수를
  올리면 점수가 실력을 뜻하지 않는다
- **관전** — 남의 대진을 무대에 올린다(`watchFight`). 보던 시점 그대로 갈아타고,
  정산은 언제나 내 결과로 한다 — 한 라운드의 전투들은 동시에 벌어진다
- **홈 로비** — 좌측 패널(메뉴·전적·접속 상태), 전용 배경(SVG 능선 + 간판
  드래곤). **서버가 필수다** — 연습·로컬 봇 로비는 삭제했다
- **튜토리얼** — 대본(`sim/tutorial.js`)이 정한 단계를 코치가 화면에 옮긴다.
  전용 매치메이커라 **서버 없이 돈다** — 연습을 없앤 자리를 대신한다
- **전적 · 랭크** — 판수·1위·최고·최근 5판. 순위는 **서버가** 좌석이 죽는
  자리에서 박는다(`assignRanks`), 누적은 `sim/profile.js`. LP·티어·순위표는
  `sim/rank.js` 가 표를 쥐고 서버가 `leaderboard` 컬렉션에 쓴다
- **닉네임** — 순위표와 남의 화면에 뜨는 이름. 서버가 규칙을 다시 검사한다
- **코스메틱** — 아바타 18종 · 무대 스킨. 좌석에 붙어 **남에게도 보인다**.
  보유·해금 판정은 `sim/cosmetics.js` 순수 함수, 서버가 같은 함수로 검산한다
- **시즌 패스** — 판마다 경험치, 단계가 오르면 보상이 열린다(`sim/pass.js`).
  트랙은 **한 줄 25칸**이고 칸마다 보상이 하나다(물건 12 · 젬 13). **기본은
  자물쇠** — 프리미엄을 사야 열린다. 무료 칸은 9개(`pass.json` 의 `freeLevels`)
  이고 그중 7칸이 물건이다. 해금 단계의 단일소스는 `cosmetics.json`, 무료
  여부의 단일소스는 `pass.json` — 한 값을 두 곳에 적지 않는다
- **젬 상점 · VXShop 결제 배선** — 지급 표는 `sim/store.js`, 서버 훅
  `$onItemPurchased` 가 그 표를 읽는다. 결제창은 플랫폼이 쥔다(`game/src/vxshop.js`)
- **일일 미션** — 매일 3개, UTC 자정에 갈린다. 보상은 패스 경험치다. 오늘의
  목록은 **저장하지 않고** 날짜+계정으로 다시 계산한다(`sim/missions.js`) —
  저장은 진행도와 수령 여부뿐. 판이 끝날 때 서버가 세고, 수령도 서버가 판정한다
- **설정** — 홈과 인게임이 같은 창을 연다. 효과음·배경음 슬라이더 · 언어 ·
  화면 효과 줄이기 · 내 계정 · 데이터 초기화 · **항복**(인게임). 위험한 둘은
  확인을 두 번 받는다
- **항복 · 계정 초기화** — 서버가 판정한다. 항복은 좌석을 죽이고 그 자리로
  순위를 박은 뒤 전적·미션·패스까지 반영한다(마감과 같은 `settleRanks`).
  초기화는 프로필과 순위표 줄을 지우되 **결제 기록은 남긴다** — 그건 영수증이다
- **한국어 · 영어** — 문자열 표(`game/src/i18n.js`)와 `t(key)`. 데이터의
  이름·설명은 `{ ko, en }` 이고 `textOf` 가 푼다. 서버·규칙은 사유를 **코드로**
  보내고 화면이 옮긴다 — 문장을 보내면 영어 화면에 한국어가 뜬다
- **전투 연출** — 승리 이펙트 5종, 이긴 아바타의 마무리, 맞은 아바타 위 피해 숫자
- **소리** — 효과음 11종 + 배경음 2곡(홈·전투). 소리를 내는 곳은
  `game/src/audio.js` 한 곳뿐이고 바깥은 `sfx('hit')` 처럼 사건 이름만 부른다.
  첫 손짓 전에는 브라우저가 막으므로 그때까지 미뤄 둔다. 볼륨은 설정에서 매번
  새로 읽어 슬라이더가 끄는 동안 바로 들린다. 파일 반입은
  `tools/audio-import.mjs` 의 표가 단일소스다(ogg 그대로 — 변환기가 없다)

`npm run check` — 불변식 28종 + 테스트 690개(40 파일).
`npx -y @agent8/gameserver-node test` — 54개.

## Not Implemented

- **증강체 · 광고 보상**
- **서버가 경제를 안 쥔다** — 배치 제출은 형식·범위만 검산한다(`sim/submit.js`:
  실재하는 유닛 · 성급 1~3 · 내 진영 칸 · 한 칸에 하나 · 인원 ≤ 레벨 ·
  아이템 실재/칸 수). "정말 그 말을 샀는가"(골드·합성·아이템 획득)는 아직
  안 센다. 그러려면 서버가 상점과 지갑을 쥐어야 한다
- **VXShop 대시보드 상품 등록** — 코드는 붙었다. 대시보드에 4개 상품을 그대로
  등록하고 배포본에서 결제를 확인하는 일이 남았다: `docs/vxshop-상품등록.md`

## 알아 둘 것

- 서버 API 는 `server/src/server.ts` 에 있다: 로비 입장 · 매칭 큐 · 보드/레벨
  정찰 · 라운드 마감 · 전적 · 순위표 · 겉모습 · 결제 훅. 데이터는 JSON 을 직접
  import 한다 — `loadData` 의 Node 분기는 번들러가 IIFE 로 묶으며
  `import.meta.url` 이 비어 못 쓴다
- **로컬(`localhost:5180`)에서는 서버에 못 붙는다.** 플랫폼이 iframe URL 로
  넣어 주는 `?auth=` 서명이 없어서다 — 코드 결함이 아니다. 서버가 걸린 것은
  배포본(verse8 iframe)에서만 확인된다. 홈은 그 상태를 화면으로 구분해 말한다
