# Context — Reroll Beasts

## Project Overview

가로형 모바일 **오토체스**. 몬스터 26종을 사서 육각 판에 배치하고, 라운드마다
로비의 다른 7명과 겨룬다. 총 23라운드, 시작 체력 40.

핵심 경계가 하나 있다: **전투 판정과 렌더가 분리되어 있다.**
`sim/combat.js` 가 `(보드A, 보드B, 시드) → 전투 로그` 를 내고, 화면은 그 로그를
**재생만** 한다. 같은 코드로 헤드리스 밸런스 시뮬과 서버 검증이 가능하다.

렌더는 three.js + glTF (바닐라 JS, React 아님). 에셋은 전량 CC0 —
Quaternius 몬스터, KayKit 육각 타일, Kenney UI.
